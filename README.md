# 📊 Syntecxhub Sales Performance Dashboard

A Power BI dashboard created as part of the **Syntecxhub Data Analysis Internship** to analyze retail sales performance using the Sample Superstore dataset.

---

## 📌 Project Overview

This project analyzes sales data from a retail superstore and presents key business insights through an interactive Power BI dashboard. The dashboard helps identify sales trends, top-performing products, regional performance, and category distribution.

This project was completed for **Week 1 – Data Analysis Internship Task** at Syntecxhub.

---

## 🎯 Objectives

* Import and clean a sales dataset.
* Analyze monthly, quarterly, and yearly sales trends.
* Compare sales across different regions and categories.
* Identify top-selling products.
* Build an interactive dashboard in Power BI.

---

## 🛠️ Tools & Technologies

* **Power BI Desktop** – Dashboard creation and visualization.
* **Python (Pandas)** – Data loading and preprocessing.
* **Jupyter Notebook** – Data analysis.
* **CSV Dataset** – Sample Superstore sales dataset.

---

## 📈 Dashboard Features

The dashboard includes:

* 💰 Total Revenue KPI
* 📦 Total Orders KPI
* 🛍️ Total Products KPI
* 🗂️ Total Categories KPI
* 📅 Monthly Sales Trend
* 🌍 Sales by Region
* 📊 Sales by Category
* ⭐ Top 10 Selling Products
* 🎛️ Interactive slicers for Year, Region, and Category

## 🚀 How to Run This Project

1. Download or clone this repository.
2. Open `SalesDashboard.pbix` using Power BI Desktop.
3. Open `sales_analysis.ipynb` in Jupyter Notebook to view the data analysis process.
4. Ensure the dataset is located inside the `data` folder.
